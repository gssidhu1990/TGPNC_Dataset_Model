

# TGPNC_Dataset_Model

This folder contains lightweight student model developed for the TG-PNC framework: **Teacher-Guided Punjabi News Classification**.

## Contents

- **Dataset:** Data will be made available on request.
- **Student Model:** A lightweight TF-IDF + Logistic Regression model trained using teacher-guided knowledge distillation from the optimized MuRIL teacher model.
- **Purpose:** To support efficient, reproducible, and deployment-friendly Punjabi news classification.
