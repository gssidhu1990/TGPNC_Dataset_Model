

# TGPNC_Dataset_Model

This folder contains the dataset and lightweight student model developed for the TG-PNC framework: **Teacher-Guided Punjabi News Classification**.

## Contents

- **Dataset:** Preprocessed Punjabi news articles collected from multiple online Punjabi news sources and organized into nine news categories.
- **Student Model:** A lightweight TF-IDF + Logistic Regression model trained using teacher-guided knowledge distillation from the optimized MuRIL teacher model.
- **Purpose:** To support efficient, reproducible, and deployment-friendly Punjabi news classification.

## Note

The dataset and model are provided for academic and research purposes. Users should cite the associated research article when using these resources.
